# 검증 기록과 적용 범위

검증 기준일: 2026-10-25. 실제 회사 PPT, 사내 API 키, 사내 모델 서버는 사용하지 않았습니다.

## 실행 검증

Windows의 Python 3.12 환경에서 표준 라이브러리만으로 가상 OOXML PPTX와 PNG를 생성해 **추출·검토·공개·이미지 연결 테스트 18개를 통과**했습니다. 설치기 별도 테스트도 통과했습니다. 지원 대상으로 안내한 Python 3.10/3.11의 별도 실행 검증은 하지 않았습니다.

- 실제 프레젠테이션 순서가 내부 slide 파일명 순서와 다른 문서, 숨김 슬라이드, 한글/그리스 문자/음수·단위, 그룹 그림과 발표자 노트의 원문·관계 보존.
- 원본 PPTX 바이트/SHA-256 보존, 원문·미디어 변조 탐지, ZIP 경로 이탈/DTD/매크로 위장/대소문자 경로 충돌 거부.
- 미검토 자료 공개 차단, Markdown 검토 상태·주장 ID 누락 탐지, 인용 문자열/숫자 기록/슬라이드 근거 불일치 탐지.
- OCR만으로 시각 주장을 확인했다고 기록하면 거부, 다른 슬라이드 그림 연결과 등록되지 않은 렌더 탐지.
- 같은 입력의 새 run 생성, 같은 공개 대상 덮어쓰기 거부, 완료본을 만든 후 공개 경로로 이동, 원문 코드 블록의 문자와 실제 위키링크 구분.
- 수동 PNG 매핑 확인 필수, 한글 파일명 연결, 누락/추가 파일·잘못된 패턴·경로 이탈·기존 렌더·원본 변조 거부.
- PNG의 청크/체크섬/압축 데이터/크기 검사, 잘린 이미지와 손상된 이미지 거부. 이미지 내용을 원본 슬라이드와 의미적으로 비교한 검사는 아닙니다.
- 설치 드라이런, 한글·공백 경로, 설치 영수증 해시, 사전 충돌 시 무변경, 재설치 거부, 잘못된 경로/누락 Vault 거부, 중간 실패의 기록 보존.

## 정적·절차 검토

- PowerShell 렌더 스크립트의 구문 분석 확인.
- Anthropic 공식 문서에 따른 프로젝트/사용자 파일 위치와 스킬 호출 방법 확인.
- 별도 검토에서 12장 문서의 일부 파일럿 후 재개, 숨김 슬라이드, OCR/Vision 분리, 문서 리비전 충돌, 크롭 근거와 파생 계산 처리의 일관성 확인.
- ZIP에 `.claude` 폴더가 포함되는지, 문서 링크와 필수 파일, 전체 파일 체크섬을 확인해 배포합니다.

## 아직 검증하지 않은 것

- 실제 Windows 데스크톱 PowerPoint COM 렌더 실행. 이 제작 환경의 PowerShell 실행 정책으로 런타임 검증이 제한되어 정책을 변경/우회하지 않았습니다. 구문 검사 통과는 실제 렌더 성공을 뜻하지 않습니다.
- `install.cmd`의 실제 Python launcher 경로 선택. Python 설치기 자체는 실행 검증했습니다. CMD 실행기가 없는 환경은 README의 승인된 Python 절대경로 명령을 사용합니다.
- 회사 승인 LLM/Vision 게이트웨이의 이미지 전달과 모델의 실제 도표 판독 능력, 실제 사내 파일의 렌더 충실도, 폰트/애니메이션/OLE의 시각적 정확성.
- 자동으로 모든 정보 손실·잘못된 물리 해석·틀린 단위 의미·누락된 주장·조작된 수동 검토 선언을 탐지하는 기능. 이 패키지의 검증기는 그러한 사실 판정기가 아닙니다.

따라서 첫 사용은 3~5장의 원본/노트/그림을 사람이 비교하는 파일럿으로 진행합니다. 검토되지 않은 부분은 표시하고, 판단에 중요한 수치·조건·도표 연결은 원본과 직접 대조합니다.
